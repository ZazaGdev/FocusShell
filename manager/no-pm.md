# FocusShell runs without the PM

"Run the PM" is off in Settings (the default), so there is no `pm` session this run. You keep the
board yourself, as well as doing your own work:

- Read `<data>\pm\board.md` and follow it as your own rules: adding items, short titles,
  order, priority, versions, merging duplicates, closing, Me, reminders (`> Due:` and
  `> Repeat:` lines), notes and ideas. Where it says "you" it means whoever keeps the board,
  which this run is you. The rest of the PM's folder is for the PM and does not apply to you.
- Skip every step in your rules that messages `pm`: there is nobody to tell. When a report
  changes a task, tidy the board yourself instead.
- Board questions the user would have asked the PM ("what's next?", "what's stale?",
  "remind me ...") come to you; answer them from the task files.
- Lead work stays as it is. Your rule that Me is not a project still holds: never hand a
  Me item to a lead.
